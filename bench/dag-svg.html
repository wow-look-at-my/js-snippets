dag-view: canvas vs SVG frame cost

Each case pans the same layout for a fixed number of frames. frm is the gap between frame starts in ms, so it includes paint and raster. At vsync a frame never reads under 1000/refresh-rate. build is the time to the first frame. Keep this tab in front while it runs. It takes about a minute.

Both SVG modes run the element's own draw() into a 2D context that writes SVG, so they draw every treatment the canvas draws. The parity row and the pictures below it compare the two pixel by pixel. canvas is the shipped element. svg-rebuild makes a new SVG DOM every frame, the way the canvas redraws every frame. svg-pan builds the whole graph once and pans it with a transform; any zoom pays its build again.
